For everyone: install and use

What you need

  • Windows 10 or 11, 64-bit.
  • For signing: your DSC USB token and its driver installed (the same driver your other signing software uses), and the token's PIN.

Install

  1. Download PBJStudio-Setup-1.2.0.exe from the Releases page of this repository.
  2. Your browser may warn that the file "isn't commonly downloaded". This is normal for new free software without a paid code-signing certificate. In Edge: open Downloads (Ctrl+J), click the ... next to the file, choose Keep, then Show more > Keep anyway. In Chrome: click the warning, then Keep.
  3. Double-click the file. If Windows says "Windows protected your PC", click More info, then Run anyway.
  4. Accept the licence and click Install. No administrator rights are needed.
  5. Tick Launch PB&J Studio at the end, or start it from the Start menu.

To remove it, use Settings > Apps > Installed apps > PB&J Studio > Uninstall.

Open a PDF

Use File > Open, drag a PDF onto the window, or pick one from the recent files list. If PB&J Studio is already running, opening another PDF from Explorer adds it as a new tab in the same window. The program works on a private copy. Your original file is not changed until you Save (Ctrl+S) or Save As (Ctrl+Shift+S). Every change can be undone (Ctrl+Z) and redone (Ctrl+Y).

Pick pages from several PDFs (Multiple PDFs)

Use this when you need one PDF made from chosen pages of several files, for example pages 3-5 of one report, page 9 of another, and a covering letter.

  1. Open the Multiple PDFs tool in the tools pane (or Tools > Multiple PDFs).
  2. Add PDFs... (or drop PDF files on the file list, or Add open document). A password-protected file asks for its owner password, the one that also lets you change the file.
  3. Click a file in the list. Its pages appear as thumbnails. Click the pages you want (Ctrl or Shift for several) and press Add selected, or double-click a page to add just that one. You can also type pages, such as 3-5, 9, and press Add range; they are added in the order you type them (5-3 counts down).
  4. Repeat for the other files. The pages you add collect under 3. Your new PDF, in the order you added them. Each thumbnail shows its place in the new file and the file name and original page number under it.
  5. Arrange them: drag pages to a new place, or select pages and use the arrows, To top, To bottom; turn pages with the rotate buttons; take pages out with Remove (or the Delete key).
  6. Press Save new PDF.... The new file opens in a new tab unless you untick the box.

Your original PDFs are never changed. Large PDFs stay quick because thumbnails are drawn only for the pages you are looking at.

Sign a PDF at many places

  1. Open the PDF and choose Multi-Sign (DSC) in the tools pane.
  2. Pick a detection mode, or click place by hand. The places are drawn on the pages.
  3. Plug in your token, choose your certificate and click Sign.
  4. Enter the token PIN when asked. The signed file opens in a new tab.

The visible signature looks like Acrobat's: your name large on the left, "Digitally signed by ..." and the date on the right, plus Reason and Location lines when you fill them in. It uses the Myriad Pro font when Adobe Acrobat is installed on the PC (read from the PC, never shipped with this app), and otherwise the bundled Source Sans 3 (Adobe's open-source, Myriad-style font), so it looks right on every PC.

Preferences (Ctrl+K)

Open Edit > Preferences or press Ctrl+K. Everything here takes effect as soon as you press OK.

Create links from web addresses Web addresses (http, https, www) in the text become clickable; click one and confirm to open it in your browser.

Snapshot options Fixed resolution in pixels per inch, and "open each snapshot as a one-page PDF" so you can mark it up.
Touch mode Auto, always on (125% larger interface) or off. Menus keep their normal size.

Do not show edit warnings Skips the question before redacting or flattening a form. Untick it (Reset all warnings) to see them again.

Select tool (V): drag over text; the selected lines are shaded. Ctrl+C copies, or use the quick actions. Snapshot tool (G): drag an area; it is copied to the clipboard as a picture, ready to paste. File > Send to WhatsApp: saves a copy of the open PDF (with your current changes), puts the file on the clipboard and opens WhatsApp. In the chat, press Ctrl+V or drag the file in from the Explorer window that opens.

Settings are stored in %APPDATA%\KcsPdfStudio\settings.json.

Not included, and why: online storage options (the app has no cloud features), "read articles" and image-first selection (the viewer has no article or image selection), and Explorer thumbnail previews for PDFs (they need a native Windows shell extension that cannot be shipped safely from a .NET app).

Keyboard shortcuts

Ctrl+O open - Ctrl+S save - Ctrl+Shift+S save as - Ctrl+P print - Ctrl+W close tab - Ctrl+Z / Ctrl+Y undo / redo - Ctrl+F find - Ctrl+G go to page - Ctrl+0 / 1 / 2 fit page / actual size / fit width - Ctrl+K preferences - F11 full screen. With single-key shortcuts turned on: V select text - H hand - G snapshot.

If something goes wrong

The app writes unexpected errors to %APPDATA%\KcsPdfStudio\error.log. Send that file when you ask for help.
